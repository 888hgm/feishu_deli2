# 关键节点完成汇总表 · v1.1.3

飞书多维表格仪表盘插件。按“上市月份 × 产品公司”生成类似 Excel 的汇总表，每个节点展示两列数量与完成率；支持记录计数、SKU 累加和每月合计。

这是此前“关键节点完成汇总表”的更新，与原多横轴柱状图插件分开使用。

## 从旧版升级

把本包内容更新到**现有汇总表的 GitHub 仓库根目录**，再到飞书开发者中心更新发布，无需新建插件。请一并上传源码与新 `dist`，确认当前运行版本为 **v1.1.3**。

- 旧字段映射、标题、公司范围、节点顺序、列宽和标红阈值均保留。
- v1.1.3 新增“仅统计进行中和延期项目”，默认不勾选，升级后原统计范围不变。
- 新增统计方式，升级默认使用“记录数量”。
- 新增每月合计行，默认显示；在“表格设置”可取消勾选并保存。
- **状态非空仍是参与前提。计划数量排除单独斜杠但计入空白；实际数量排除单独斜杠和空白。完成率仍只看状态，不因时间内容排除完成或未完成量。**

## 本版统计规则

以每条记录的每一个节点为单位，先去掉“是否完成”字段首尾空格：

| 节点状态 | 计划数量列 | 实际数量列 | 完成率 |
| --- | --- | --- | --- |
| 空白 | 不计入 | 不计入 | 不计入 |
| 完成 | 按计划时间规则计入 | 按实际时间规则计入 | 计入完成量 |
| 未完成 | 按计划时间规则计入 | 按实际时间规则计入 | 计入未完成量 |
| 其他非空内容 | 按计划时间规则计入 | 按实际时间规则计入 | 不进入完成率分母，页面会提示 |

**计划、实际两列分别判断时间，因此数量可以不同。**

| 时间内容（去掉首尾空格后） | 计划数量 | 实际数量 |
| --- | --- | --- |
| 空白 | 计入 | 排除 |
| 单独的 / 或 ／ | 排除 | 排除 |
| 日期或其他非空内容 | 计入 | 计入 |

只排除独立斜杠，`2026/11/12` 这种日期仍正常计入。计划、实际时间字段重新成为必选项，旧节点如未映射请补选；已删除的时间字段需重选，避免将未读取到的数据误当空白。

**完成率不使用两列数量相除。即使两个时间都为空或斜杠，只要状态为“完成／未完成”，仍进入完成率的相应分子或分母。**

按节点分别判断。例如，同一记录的“产品设计是否完成”为空、“首样评审是否完成”为未完成：产品设计三项指标不计入，首样评审正常参与。不会整条排除源记录。

## 两种统计方式

在“数据范围 → 统计方式”切换：

| 方式 | 两列数量 | 完成率 |
| --- | --- | --- |
| 记录数量 | 状态非空后，按相应时间规则每条计为 1 | 完成条数 ÷（完成条数 + 未完成条数） |
| SKU数量累加 | 状态非空后，按相应时间规则分别累加所选 SKU 字段 | 完成 SKU 合计 ÷（完成 SKU 合计 + 未完成 SKU 合计） |

选择 SKU 模式后，在“SKU数量字段”中选择对应数字字段。自动识别同名“SKU数量”数字字段；名称不一致时可以搜索并手动选择，不会自动取第一个数字金额字段。

- SKU 空白或 0 按 0 处理；状态非空但 SKU 为 0 的记录会提示数量。
- 支持非负数字、数字文本和正常千分位，例如 `1,234`。
- 有效记录的 SKU 为负数或不可解析的文本时，提示错误并停止展示本次统计，避免生成不完整结果。
- 不在所选月份／公司范围、或所有启用节点状态均为空的记录，其 SKU 不参与计算。
- 记录模式不会读取或校验 SKU 值。
- 分母为 0 时显示 `—`，包括 SKU 全为 0 的情况。

## 每月合计行

默认在每个月的第一行显示“合计”。在“表格设置 → 显示每月合计行”取消勾选即可隐藏；保存后重新打开会保留选择，CSV 导出也遵循开关。

合计只汇总**当前配置选中的公司**，包含下方没有记录的空公司行，不包含未选公司。每个节点单独计算：

```text
月合计数量 = 所选公司该节点数量之和
月合计完成率 = 所选公司完成量之和 ÷（所选公司完成量之和 + 所选公司未完成量之和）
```

**不直接平均各公司百分比，也不使用四舍五入后的百分比计算。**

例如公司 A 完成 1、未完成 1，公司 B 完成 9、未完成 1，月合计是 `10 ÷ 12 = 83.3%`。

SKU 模式下，例如 A 完成 SKU 为 20、未完成为 30，B 完成 SKU 为 80、未完成为 0，合计是 `100 ÷ 130 = 76.9%`，而不是两个公司完成率的平均值。

合计行不被再次加入公司行计算，不会重复统计。合计完成率也使用当前低完成率标红阈值。

## 第一次发布到飞书

1. 解压精简包。上传的是解压后的文件与文件夹，不是 ZIP 本身，也不要在仓库根目录再包一层项目文件夹。
2. 新建一个独立的公开 GitHub 仓库，例如 `feishu-milestone-table`。已有汇总表仓库则直接更新原仓库。
3. 使用 `Add file → Upload files` 上传并提交。包中文件少于 100 个，不包含测试、依赖或演示数据。
4. 根目录应直接存在 `package.json`、`src`、`scripts`、`dist`；`dist` 根目录下直接存在 `index.html`。
5. 在此前使用的飞书多维表格开发者中心，创建／更新类型为“仪表盘插件”的商品。“插件代码 Github 地址”填写仓库地址，如 `https://github.com/你的用户名/feishu-milestone-table`，完成发布。
6. 回到仪表盘，通过添加组件／插件入口添加或打开自己的插件。升级后核对配置界面版本 **v1.1.3**。

飞书入口名称可能随版本变化，请沿用你之前成功发布汇总表的流程。公开仓库便于飞书读取；`package.json` 中 `private: true` 是 npm 设置，不代表 GitHub 仓库是私有的。

## 首次配置

1. 在“数据范围”选择数据表、“上市时间”和“产品公司”字段。支持搜索选择。
2. 选择统计方式；SKU 模式再选择 SKU 数字字段。
3. 在“节点字段 → 批量选择节点”勾选节点。每个节点必选计划时间、实际时间和“是否完成”三个字段。
4. 可以手动添加节点、启用／隐藏节点、上下调整顺序，以及修改两列数量及完成率的表头名称。
5. 在“数据范围”选择上市月份和产品公司，可调整公司顺序。
6. 在“表格设置”修改标题、月份排序、字号、小数位，选择是否显示每月合计，设置提醒和列宽。
7. 点击“添加到仪表盘”或“保存配置”。

“全部”模式包含当前可读记录中的值及单选字段现有选项；出现新选项时自动加入。“勾选范围”固定当前选择。每个月都保留所有选定公司，无记录时显示 `0、0、—`。

## 列宽和标红

- 拖动表头右侧边线调整列宽，双击恢复该列默认值。“表格设置 → 列宽调整”也可输入像素值或全部恢复默认。
- 月份列 72–600px，公司列 100–800px，节点各列 64–600px。固定列位置同步更新；隐藏、重新启用或重排节点后宽度跟随对应列。
- 长期保留列宽需在组件配置中调整后保存；查看／全屏状态也可临时拖动，重新打开时使用已保存配置。
- 键盘聚焦边线后，方向键调整 10px，Shift 加方向键调整 1px，Home／End 到边界，Delete 恢复默认，拖动时 Esc 取消。
- “表格设置 → 完成率提醒”可开启低于阈值标红。默认关闭，升级保留旧设置。
- 阈值例如 80：低于 80% 红字，等于 80%、高于 80% 或 `—` 保持原色。按原始比率比较，仅影响完成率列，包含每月合计行。

## 数据范围和使用限制

- 读取当前用户有权访问的全表记录，使用插件内月份／公司范围；**不跟随仪表盘外层全局筛选或源表视图筛选**。
- 上市时间仅用于分组，按两位／四位年份和月份排序，如 `26年3月` 按 2026 年 3 月处理；不同名称的单选项不自动合并。
- 月份或公司为空的记录不参与分组，并显示提示。状态非空的其他值按时间规则参与数量，但只有精确的“完成／未完成”参与完成率。
- 计划、实际时间只影响各自数量，完成率继续只由状态及当前记录／SKU统计方式决定。
- 顶部表头和左侧两列固定；节点多时在表格内横向滚动。可使用飞书组件全屏。
- 悬停完成率查看完成量、未完成量、分母、状态非空记录数和排除的空状态数，SKU 模式显示相应单位。
- “导出 CSV”包含当前范围、表头和可见合计行；UTF-8 BOM 便于 Excel 打开。CSV 不包含列宽和文字颜色格式。
- 数据变化通知、手动刷新及可见页面每 5 分钟定时刷新；每页读取 200 条记录，按 ID 去重，中途失败不显示部分统计。
- 独立浏览器页面仅显示连接提示，包内不内置演示数据；需从飞书仪表盘打开读取源表。
- 不需要填写 App Secret 或个人令牌。插件只读取源表，保存的是字段映射、范围及显示配置。
- 本插件是汇总表，不包含柱状图插件的点击下钻功能。

## 项目状态筛选（v1.1.3）

在“配置 → 数据范围 → 统计方式”下方勾选“仅统计进行中和延期项目”。默认不勾选，旧配置保持原统计范围。自动匹配名为“项目状态”的单选字段，也可手动选择其他单选字段。保存配置后生效于仪表盘查看及全屏。

勾选后只保留去除首尾空格后精确等于“进行中”或“延期”的记录。其他状态（包括取消、完成、暂停、规划中及空白）不参与节点数量、SKU累加、完成率、每月合计和CSV导出；完成率仍按节点的“完成／未完成”计算。月份和公司选项及选定范围继续保留，无有效数据时为0、0、—。字段缺失或改为非单选类型会提示重新选择，不会退回全量统计。五分钟定时刷新、手动刷新和源表变更更新机制保持不变。
